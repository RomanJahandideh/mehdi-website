# Mehdi Vahabisani portfolio

A standalone, responsive portfolio website built with plain HTML and CSS.

## Preview

Open `index.html` in a browser. The page uses Google Fonts and a photograph hosted by Unsplash, so those assets require an internet connection.

## Publish

Create a GitHub repository named `mehdi-website`, then push this folder as that repository's root. The existing parent repository has its own remote and should remain unchanged.
