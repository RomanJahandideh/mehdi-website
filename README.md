# Mehdi Vahabisani portfolio

A standalone, responsive portfolio website built with plain HTML, CSS and JavaScript. No build step.

## Files

- `index.html` – page content (kept in sync with the CV)
- `style.css` – styles
- `script.js` – interactions: model viewer, accordion, process stepper, filters, copy buttons, contact form
- `assets/Mehdi_Vahabisani_CV.pdf` – downloadable CV (replace this file to update it)

## Preview

Open `index.html` in a browser, or serve the folder (for example with VS Code Live Server). Only the Google Fonts need an internet connection; every visual is inline SVG, so nothing else can break.
